# Tidalyst

Farm-management software for shellfish and aquaculture, built for the water.

Tidalyst is a web app your crew uses on a phone, on the water. It brings farm records and water conditions together, so you can see what's in the water, how each batch is doing, and what to do next.

- **Inventory:** an exact count from every planting, harvest and loss the crew records.
- **Water:** tide, water temperature, wind and harvest-area status for your sites.
- **Seed to sale:** each batch followed from seed to harvest.
- **Reporting:** records ready for USDA reports.

**The record belongs to the farm.** We don't sell data, we don't show one farm another's numbers, and a correction sits beside the original entry, never over it.
